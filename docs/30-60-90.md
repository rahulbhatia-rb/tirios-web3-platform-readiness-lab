# 30 / 60 / 90 Day Platform Roadmap

## 30 days
- remove remote code execution
- restore and validate persistence and auth
- inventory real contract/backend ownership logic
- define lifecycle states and events
- establish environments, secrets, CI/CD, and logging

## 60 days
- event indexer with checkpoints and idempotency
- RPC failover
- wallet transaction lifecycle tracking
- contract/backend reconciliation
- production health dashboards and alerts

## 90 days
- reorg-safe replay
- staking/reward reconciliation
- tested backup/restore
- security review of privileged flows
- deployment promotion gates
- capacity and cost visibility
